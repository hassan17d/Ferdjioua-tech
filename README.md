# Ferdjioua Tech

صفحة ويب ثابتة (HTML واحد) تعرض كود Downloader وخطوات تثبيت التطبيقات على Smart TV وFire TV.

## المميزات
- كود Downloader كبير مع زر نسخ
- رابط مباشر قابل للنسخ
- شرح الاستخدام في ثلاث خطوات
- بطاقات تطبيقات مع أيقونات
- تصميم عربي (RTL) متجاوب مع الجوال والوضع الداكن

## التعديل
افتح `index.html` وعدّل القيم داخل `CONFIG` في آخر الملف:
الكود، الرابط، قناة تيليجرام، وقائمة التطبيقات (الاسم، الوصف، الرابط، الأيقونة).

## النشر على GitHub Pages
Settings ← Pages ← Source: Deploy from a branch ← Branch: main ← Save
